# 本地题库模块 v2.0 - 控制台优化版

## 概述

本地题库模块v2.0是一个完全控制台化的题库管理系统，支持前后端分离架构，无需Web界面，完全在控制台中进行操作。该模块可以扫描tiku文件夹中的题库文件，进行智能解析和缓存，并支持生成注入脚本。

## 架构优化

### 核心特性
- **完全控制台化** - 无需Web界面，所有操作在控制台完成
- **前后端分离** - 后端API服务 + 控制台管理界面
- **智能文件管理** - 自动扫描tiku文件夹，支持文件选择
- **自动重命名缓存** - 文件自动重命名为tiku.txt并缓存为tiku.json
- **注入脚本生成** - 将txt转换为js注入脚本
- **测试用例支持** - 自动生成测试用例

### 目录结构

## 使用方法

### 重要提醒
**题库文件命名建议**: 请将题库文件命名为英文，避免使用中文字符，以确保系统兼容性和稳定性。

### 1. 安装依赖
```bash
cd local_tiku_module
npm install
```

### 2. 启动后端服务
```bash
npm start
# 或者开发模式
npm run dev
```

### 3. 使用控制台管理
```bash
npm run console
```

### 4. 生成注入脚本
```bash
npm run injector
```

### 5. 运行测试
```bash
npm test
```

## 📖 详细功能说明

### 控制台管理 (console_manager.js)

运行 `npm run console` 启动控制台管理界面：

```
📚 本地题库管理系统 v2.0
============================================================
功能：题库文件管理、解析、缓存和智能匹配
支持格式：.txt, .doc, .docx
编码支持：UTF-8, GBK, GB2312
============================================================

主菜单
1. 扫描题库文件夹
2. 选择并导入题库文件
3. 查看当前题库状态
4. 清空题库缓存
5. 测试题库匹配
6. 生成测试用例
0. 退出
```

#### 主要功能：
- **扫描题库文件夹** - 列出tiku文件夹中的所有支持文件
- **选择并导入** - 选择文件进行导入，自动重命名和缓存
- **查看状态** - 显示当前题库的详细信息
- **清空缓存** - 清除所有缓存数据
- **测试匹配** - 测试题库匹配功能
- **生成测试用例** - 自动生成测试用例文件

### 注入器 (tiku_injector.js)

运行 `npm run injector` 生成注入脚本：

```
题库注入器 v1.0
============================================================
功能：将txt题库文件转换为js注入脚本
============================================================

扫描到 2 个txt文件:
   1. 微信小程序题库.txt (15KB)
   2. tiku_test.txt (2KB)

🔄 开始转换所有txt文件...
转换完成: 微信小程序题库.txt -> 微信小程序题库.js
   题目数量: 150
   保存路径: ../src/scripts/微信小程序题库.js
```

#### 生成特性：
- **智能解析** - 自动识别题目类型和结构
- **相似度匹配** - 内置字符串相似度算法
- **批量处理** - 支持批量题目处理
- **全局暴露** - 将功能暴露到window.tikuInjector

### 后端API服务

#### 新增API端点：

1. **扫描tiku文件夹**
   ```
   GET /api/scan-tiku-folder
   ```

2. **从tiku文件夹导入**
   ```
   POST /api/import-from-tiku
   Body: { "fileName": "微信小程序题库.txt" }
   ```

3. **原有API保持不变**
   - `GET /health` - 健康检查
   - `GET /api/tiku-info` - 题库信息
   - `POST /api/get-answer` - 获取单个答案
   - `POST /api/get-batch-answers` - 批量获取答案

## 工作流程

### 标准使用流程：

1. **准备题库文件**
   ```bash
   # 将题库文件放入tiku文件夹
   cp "微信小程序题库.txt" tiku/
   ```

2. **启动后端服务**
   ```bash
   npm start
   ```

3. **使用控制台管理**
   ```bash
   npm run console
   # 选择 "2. 选择并导入题库文件"
   # 选择对应的文件进行导入
   ```

4. **生成注入脚本**
   ```bash
   npm run injector
   # 自动转换所有txt文件为js注入脚本
   ```

5. **测试功能**
   ```bash
   npm test
   # 运行测试用例验证功能
   ```

## 故障排除

### 常见问题：

1. **题库文件无法识别**
   - 检查文件格式是否为.txt, .doc, .docx
   - 确认文件编码格式
   - 检查题目格式是否符合规范

2. **匹配准确率低**
   - 调整相似度阈值
   - 检查题目文本是否完整
   - 确认题库数据质量

3. **服务启动失败**
   - 检查端口3001是否被占用
   - 确认依赖包已正确安装
   - 查看错误日志信息
