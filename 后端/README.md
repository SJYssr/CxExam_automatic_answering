# CxExam自动答题系统

## 项目简介

CxExam自动答题系统是一个基于Electron框架开发的智能答题辅助工具，集成了本地题库和AI智能答题功能。该系统能够自动识别题目类型，提供准确的答案，支持多种考试场景。

## 功能特性

### 🚀 核心功能
- **智能答题**: 集成DeepSeek AI API，提供智能答题服务
- **本地题库**: 内置本地题库系统，支持离线使用
- **多题型支持**: 支持单选题、多选题、判断题、填空题、简答题
- **自动识别**: 自动识别题目类型和答案格式
- **注入功能**: 支持目标程序注入，实现自动化操作

### 🔧 技术特性
- **跨平台**: 基于Electron框架，支持Windows系统
- **模块化设计**: 采用模块化架构，便于维护和扩展
- **日志系统**: 完善的日志记录和错误处理机制
- **安全验证**: 基于MAC地址和密钥的登录验证系统

## 安装与使用

### 环境要求
- Node.js 16.0 或更高版本
- Windows 操作系统
- 网络连接（用于AI功能）

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd CxExam_automatic_answering/后端/ui
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **配置API密钥**
   - 编辑 `server.js` 文件
   - 修改 `DEEPSEEK_API_KEY` 为您的DeepSeek API密钥

4. **配置题库**
   - 编辑 `tiku.txt` 文件添加您的题库内容
   - 格式：题目 + 选项 + 答案行

### 运行程序

**开发模式运行**
```bash
npm run dev
```

**Electron模式运行**
```bash
npm start
```

**打包程序**
```bash
npm run build-win
```

## 题库格式说明

题库文件 `tiku.txt` 支持以下格式：

### 单选题
```
题目内容？
A.选项A
B.选项B
C.选项C
D.选项D
答案：A
```

### 多选题
```
题目内容？
A.选项A
B.选项B
C.选项C
D.选项D
答案：ABCD
```

### 判断题
```
题目内容？
A.对
B.错
答案：对
```

### 填空题
```
题目内容______。
答案：填空内容
```

### 简答题
```
请简述题目内容。
答案：详细解答内容
```

## API接口

### 答题接口
- **URL**: `POST /api/answer`
- **功能**: 智能答题服务
- **参数**: 
  ```json
  {
    "question": "题目内容",
    "options": ["选项A", "选项B", "选项C", "选项D"]
  }
  ```

### 题库查询接口
- **URL**: `GET /api/tiku`
- **功能**: 查询本地题库
- **参数**: `question` (题目关键词)

### 登录验证接口
- **URL**: `POST /api/login`
- **功能**: 用户登录验证

## 配置说明

```json

  "Card": "用户密钥",
  "targetPath": "目标程序路径"
```

- `PORT`: 服务端口（默认3000）

## 开发指南

### 添加新题型支持
1. 在 `server.js` 的 `parseTikuFile` 函数中添加题型识别逻辑
2. 在答题逻辑中处理新题型的答案格式

### 扩展AI功能
1. 修改 `server.js` 中的AI调用逻辑
2. 添加新的AI服务提供商支持
